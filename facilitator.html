Publish to GitHub Pages in 7 steps

1Create a free GitHub account if you do not already have one, then create a new PUBLIC repository (for example: ai-ethics-practical-book).
2Download the provided ZIP and extract it on your computer.
3Open your new repository on GitHub and select Add file → Upload files.
4Upload ALL of the extracted website contents, including index.html, the 12 practical HTML pages, quiz.html, facilitator.html, tools.html and the assets folder. Do not upload only the ZIP.
5Commit the files to the main branch. Keep index.html in the repository ROOT (not inside another folder).
6Go to Settings → Pages. Under Build and deployment, choose Deploy from a branch; select main and / (root); save.
7Open the GitHub Pages URL shown in Settings → Pages (usually https://USERNAME.github.io/REPOSITORY/). Open a lab and test a Copy button.

Presenter features at a glance

Stage mode and readable text

Click Stage mode or press F (outside text boxes). Use A+ to enlarge text. In stage mode, left/right arrow keys switch practical pages.

Copy prompts in one click

Every prompt has its own Copy button. On GitHub Pages (HTTPS), modern browsers support clipboard access. If clipboard permission is blocked, select the text manually.

Timer + note-taking

Use the per-lab countdown, tick checklist items and save notes locally. Export notes as TXT before switching devices.

Evidence over theatrics

Do not promise that ChatGPT will hallucinate, discriminate or follow an injection. Show independent verification and contrast with the prepared fictional examples.

Ethics guardrail: No real private records, passwords, proprietary documents or genuine participant data should be pasted into a public AI chat. Fictional examples are used throughout. If students volunteer real information, redirect to anonymous or synthetic material.

Useful classroom closing script

“Today we saw that using AI responsibly does not mean never using it. It means being honest about assistance, checking evidence, protecting private information, testing for unfairness and keeping humans accountable for important decisions. What is one habit you will change after this session?”
